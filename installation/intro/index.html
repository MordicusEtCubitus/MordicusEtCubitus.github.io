Installation

Installer et utiliser Python peut paraître évident :

  • Il est fourni en standard sur les systèmes d’exploitation Mac et Linux

  • Il suffit de le télécharger sur le site officiel https://www.python.org

Ensuite pour installer des librairies, il suffit d’utiliser la commande officielle pip

Mais cela est rarement aussi simple¶

Sous Windows¶

Sous Windows l’installation de librairies avec pip est problématique dès que la librairie contient un code source écrit en C, sans inclure de binaire tout compilé.

Dans ce cas pip va essayer de compiler le code source. Sous Linux et Mac: aucun problème, le compilateur GNU GCC est présent et livré en standard. Mais sous Windows, il n’y a pas de compilateur pré-installé par Microsoft et Visual Studio C++ est en général payant.

Alors l’installation échoue...

Ensuite:

  • soit vous trouvez par chance une version compilée, mais la source est-elle fiable, n’a-t-elle pas de virus ?

  • soit les développeurs en proposent une, mais pas forcément celle de votre version de Windows

  • soit vous suivez le tutoriel que j’ai écrit spécialement pour cela en 2016 : Compiler les librairies Python sous Windows

Les dépendances¶

Même sous Linux et Mac qui bénéficient d’un compilateur, bien installer une librairie Python peut être difficile si elle requiert des logiciels tiers, comme :

  • Les librairies NVidia pour utiliser votre GPU

  • Les librairies C/Fortran BLAS, LAPACK, OPENBLAS, ATLAS qui permettent d’accélerer numpy et pandas en utilisant les instructions vectorielles de vos processeurs et la parallélisation sur tous les coeurs.

  • Les drivers pour une base de données propriétaire, comme Oracle

  • ...

Si vous devez installer et optimiser ce genre de librairies pour Python cela peut s’avérer compliqué.

C’est pour cela que l’on conseille aujourd’hui d’utiliser une distribution python.

Utiliser une distribution Python¶

Une distribution Python est une suite logicielle intégrant le langage Python et de nombreux autres outils et librairies qui vous permettent de développer plus rapidement.

Les distributions Python vous apportent des gains de productivité non négligeables:

  • Elles facilitent notamment l’installation des librairies Python qui ont besoin d’être compilées sous Windows.
    Ce système ne disposant pas de compilateur par défaut, cela peut s’avérer particulièrement difficile d’installer certaines librairies Python sur les machines équipées de ce système d’exploitation.

  • Elles permettent aussi d’optimiser au mieux vos librairies, comme Numpy et Pandas en installant des librairies annexes écrites en C et Fortran permettant d’accélérer les calculs, ce que ne fera pas la commande pip habituelle qui ne sait installer que des librairies Python.

  • Elles savent pour la plupart installer d’autres logiciels et outils que Python

Il existe plusieurs distributions Python. Le site PyPa - Packaging en présente quelques unes:

  • WinPython
    Dédiée à Windows, elle peut fonctionner sur une clef USB

  • EDM
    Editée par la société Enthought cette distribution orientée data science est très inspirée de l’environnement MATLAB, elle fonctionne, sauf erreur, sous Windows, Mac et Linux

  • Python XY,
    Une autre distribution pour Windows

  • PythonAnywhere
    PythonAnywhere vous permet de développer en Python dans le cloud.

  • Pyzo
    Pyzo est une autre distribution compatible Windows, Mac et Linux proposant un environnement de développement Python orienté Data Science

  • ...

Miniforge, Mambaforge et Anaconda¶

Miniforge/MambaForge et Anaconda sont les distributions les plus utilisées: elles fonctionnent sur les systèmes Mac, Linux et Windows et utilisent une licence open source/libre.

  • Anaconda et Miniforge utilisent la commande conda par défaut pour installer des librairies et environnements virtuels Python.

  • La commande conda est écrite en Python et peut s’avérer très lente pour résoudre les problèmes de dépendances entre librairies, parfois jusqu’à plusieurs minutes/heures.

  • La distribution Mambaforge utilise quant-à-elle la commande mamba qui est l’équivalent de conda mais écrite en C++, donc beaucoup plus rapide pour résoudre les problèmes de dépendances.
    C’est la commande que nous vous conseillons d’utiliser

  • Anaconda télécharge ses librairies sur la forge principale main hébergée sur le site Anaconda.com

  • Miniforge et Mambaforge téléchargent leurs librairies sur la forge comunautaire conda-forge hébergée sur le site Anaconda.org
    Cette forge gérée par la communauté propose plus de choix de librairies et généralement dans des versions plus récentes.

  • Le choix des serveurs/forges de téléchargement reste entièrement paramétrable pour toutes ces librairies.

Attention

Depuis octobre 2021 le téléchargement de paquets sur le site Anaconda.com est payant pour les entreprises de plus de 200 employés.
Nous vous invitons à vérifier les conditions d’utilisation sur leur site, lesquelles sont très souvent sujettes à changer et l’ont déjà fait à plusieurs reprises depuis la rédaction de ce cours.

Mambaforge et Miniforge téléchargent leurs logiciels sur le dépôt communautaire Anaconda.org qui reste gratuit à ce jour.

Aussi, nous vous conseillons donc de les privilégier par rapport à Anaconda !

Note

En septembre 2023 la version 22.3.1-0 de miniforge a intégré en standard le support de la commande mamba faisant de Mambaforge un quasi doublon de celle-ci. Les deux distributions sont donc totalement identiques en dehors du nom de l’installer. L’utilisation de Mambaforge est maintenant déconseillée et ses bugs ne seront plus corrigés.

Pixi¶

Pixi est un gestionnaire de paquets, permettant de gérer des environnements de développements pour tout langage : Python, R, Rust, Javascript...

Il est rapide et respecte les bonnes pratiques de chaque langage.

Il présente 2 avantages par rapport à miniforge/mambaforge:

  • Par défaut il permet de télécharger, comme ces distributions, les logiciels sur Anaconda.org et sait donc installer tout type de logiciel, pas uniquement des librairies Python comme pip.

  • Il réalise les téléchargements en parallèle et resoud les problèmes de dépendances plus rapidement que mamba

pixi est le nouvel outil que nous conseillons. Mais il est moins mature que miniforge/mambaforge.

Pour votre projet¶

Nous vous proposons 2 procédures aux choix:

  1. L’installation avec Miniforge et les commandes conda/mamba que nous recommandons encore si vous disposez d’un GPU NVidia afin d’installer l’environnement de Rapids AI

  2. L’installation avec Pixi qui s’appuie aussi sur la forge conda mais permet de créer des projets pour d’autres langages et accélère énorément les téléchargements grace à leur parallélisation

Pixi est la solution que nous préconisons, toutefois nous manquons de recul pour l’environnement Rapids AI.
