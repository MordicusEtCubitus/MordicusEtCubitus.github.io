Installation de l’environnement de travail avec pixi

Procédure d’installation recommandée

Mais nous manquons de recul pour son usage avec la forge RapidsAI et les cartes graphiques NVidia ; dans ce cas, nous préconisons l’installation via miniforge.

Nous vous proposons une nouvelle installation de Jupyter avec Pixi qui est probablement la meilleure solution pour installer des environnements de développements, tout langage confondu, dont Python. Pixi est le nouvel uv mais n’est pas limité à Python et est compatible avec conda-forge par défaut.

Jupyter, anciennement appelé iPython notebooks, est un serveur internet permettant d’écrire et d’exécuter du code Python dans un navigateur Web.

Avertissement

Certaines captures d’écran font encore référence à un nom d’envrionnement perfectionnement-algorithmique.

Ceci sera corrigé au plus tôt.

Pour l’utilisation de django nous installerons aussi le logiciel deno, une implémentation de javascript moderne disposant d’un plugin pour jupyter.

Pixi¶

Nous vous proposons d’installer votre environnement de travail avec Pixi.

Pixi est un gestionnaire de paquets, permettant de gérer des environnements de développements pour tout langage : Python, R, Rust, Javascript...

Il est rapide et respecte les bonnes pratiques de chaque langage.

Pixi va nous servir à installer Jupyter et les autres librairies du projet.

Deno¶

Le plugin JavasSript pour jupyter, appelé kernel javascript que nous vous proposons est Deno.
Il en existe d’autres.

Nous vous proposons de l’ajouter pour vos développements web avec Django, Flask ou FastAPI par exemple.

Deno est une implémentation de JavaScript/TypeScript moderne, rapide et sécurisée. Il permet notamment:

  • Un support natif de TypeScript

  • Une meilleure sécurité en gérant des permissions de manière granulaire

  • Il inclut une bibliothèque standard, ainsi qu’un outil d’analyse statique et de formatage natif, un lanceur de tests, et bien plus encore

  • Il est compatible avec Node et npm

  • Il est écrit en langage rust et garantit ainsi rapidité et fiabilité

Et bien sûr, c’est un logiciel libre.

Etapes d’installation¶

  1. Installer Pixi: https://pixi.prefix.dev/latest/pixi/

  2. Installer Python (via pixi)

  3. Installer Jupyter et les plugins pour visualiser le cours (via pixi)

  4. Installer Deno et son plugin Jupyter

  5. Démarrer Jupyter Lab

Installation sous Windows¶

Pixi¶

Sans vouloir vous commander, rendez-vous sur la page d’installation de Pixi: https://pixi.prefix.dev/latest/installation/

Puis cliquez sur le bouton Download installer ou directement sur ce lien pour télécharger l’exécutable MSI

Toujours sans vous vouloir vous commander, lancez l’exécutable ainsi téléchargé:

Et cliquez sur Next

Enfin, démarrez l’installation en cliquant sur Install

Puis fermez la boîte de dialogue une fois l’installation terminée.

Création de l’environnement¶

Une fois l’application installée, démarrez l’invite de commande MS-DOS en saisissant CMD dans la zone de recherche:

Une fois le terminal MSDOS démarré, nous allons pouvoir utiliser pixi directement dans ce dernier.

Commencez par sélectionner le disque dur dans lequel vous souhaitez installer l’environnement de travail Jupyter.

En général c’est C:. Mais si vous avez un second disque vous pourriez vouloir utiliser ce dernier, comme D:

Nous supposons que vous avez choisi le lecteur Cpar défaut. Sur le prompt saisissez alors C: puis ENTREE.

Si vous étiez déjà sur le disque C cela ne change rien.

Ensuite, positionnez-vous dans le dossier qui contiendra votre projet pour suivre ce cours.

Par exemple: cd C:\Users\<votre login>\Documents

Puis saisissez ces commandes dans le prompt MSDOS pour installer le serveur Jupyter:

C:> pixi init formation --format pyproject
C:> cd formation
C:> pixi shell

Evidemment le symbole C:> ne doit pas être saisi, il représente le prompt de votre invite de commande MSDOS

Installez maintenant les librairies requises dans l’environnement pixi fraîchement créé.¶

(formation) C:> pixi add python=3.14 jupyterlab nodejs jupyterlab-myst myst-nb
C:> cd C:\Users\<votre login>\Documents\formation

Activez le shell pixi pour cet environnement, qui ajoutera Python et jupyter au PATH du terminal:

C:> pixi shell

Le prompt du shell sera préfixé de (formation) C:> à partir de maintenant.

Vérifiez que la commande jupyter est bien disponible et qu’elle correspond à celle de l’environnement pixi courant:

(formation) C:> where jupyter

Ce qui devrait produire quelque chose comme cela:

C:\Users\<votre login>\Documents\formation\.pixi\envs\default\Scripts\jupyter.exe

Démarrer le serveur Jupyter¶

  1. Vérifiez que vous avez bien activé le shell pixi pour l’environnement formation
    Si besoin, saisissez:

    C:> cd C:\Users\<votre login>\Documents\formation
C:> pixi shell
(formation) C:>

  2. Positionnez-vous depuis l’invite de commande dans le sous-dossier notebook contenant les supports de cours ou copiez-le dans le dossier formation

  3. Démarrez jupyter avec la commande jupyter lab

    (formation) C:> jupyter lab

Un navigateur devrait apparaître et ouvrir l’url http://localhost:8888.

Si ce n’est pas le cas, saisissez-là dans votre navigateur.

Création de l’environnement Python¶

Une fois pixi installé, il convient de créer un environnement virtuel Python (une version de python dédiée à ce cours) puis d’y installer le serveur jupyter.

Sans quitter votre terminal, saisissez la commande suivante dans le dossier de votre choix:

$ pixi init formation --format pyproject

Ceci créera le dossier formation à l’endroit ou vous exécutez la commande.
C’est dans ce dossier que votre environnement Python sera installé.

Positionnez-vous ensuite dans ce dossier et installez la suite Python requise

$ cd formation
$ pixi shell
(formation) $ pixi add python=3.14 jupyterlab nodejs jupyterlab-myst myst-nb

Voici la sortie attendue:

✔ Added python=3.14
✔ Added jupyterlab >=4.5.4,<5
✔ Added nodejs >=25.6.1,<25.7
✔ Added jupyterlab-myst >=2.6.0,<3
✔ Added myst-nb >=1.3.0,<2
$ cd formation

Activez le shell pixi pour cet environnement, qui ajoutera Python et jupyter au PATH du terminal:

$ pixi shell
(formation)  $

Le prompt du shell sera préfixé de (formation) $ à partir de maintenant.

Vérifiez que la commande jupyter est bien disponible et celle de l’environnement pixi courant:

(formation) $ which jupyter

Ce qui devrait produire quelque chose comme cela:

/home/<votre login>/pixi/formation/.pixi/envs/default/bin/jupyter

Installation de Deno¶

Toujours depuis votre terminal préféré, saisissez la commande suivante:

$ curl -fsSL https://deno.land/install.sh | sh

Nous vous invitons à accepter l’ajout de deno au PATH système.

La sortie devrait ressembler à ceci:

######################################################################## 100.0%   
Archive:  /home/<votre login>/.deno/bin/deno.zip
  inflating: /home/<votre login>/.deno/bin/deno  
Deno was installed successfully to /home/<votre login>/.deno/bin/deno

Deno was added to the PATH.
You may need to restart your shell for it to become available.

Run 'deno --help' to get started

Stuck? Join our Discord https://discord.gg/deno

Nous allons maintenant installer le kernel jupyter pour deno.

Pour cela, dans votre terminal, positionnez-vous dans le dossier pixi formation.

$ cd formation

Activez le shell pixi pour cet environnement, qui ajoutera Python et jupyter au PATH du terminal:

$ pixi shell

Le prompt du shell sera préfixé de (formation) $ à partir de maintenant.

Vérifiez que la commande jupyter est bien disponible et celle de l’environnement pixi courant:

(formation) $ which jupyter

Ce qui devrait produire quelque chose comme cela:

/home/<votre login>/pixi/formation/.pixi/envs/default/bin/jupyter

Puis installez le kernel deno:

(formation)$ deno jupyter --install
Warning "deno jupyter" is unstable and might change in the future.
✅ Deno kernelspec installed successfully at /home/<votre login>/.local/share/jupyter/kernels/deno.

Démarrer le serveur Jupyter¶

  1. Vérifiez que vous avez bien activé le shell pixi pour l’environnement formation
    Si besoin, saisissez:

    $ cd formation
$ pixi shell
(formation)$

  2. Positionnez-vous dans le sous-dossier notebook contenant les supports de cours ou copiez-le dans le dossier formation

  3. Démarrez jupyter avec la commande jupyter lab

    (formation)$ jupyter lab

Un navigateur devrait apparaître et ouvrir l’url http://localhost:8888.

Si ce n’est pas le cas, saisissez-là dans votre navigateur.

Bienvenue dans Jupyter !¶

Un notebook est une page internet dans laquelle vous pouvez écrire du code et prendre des notes en Markdown et Myst-Markdown grâce aux plugins jupyter installés.

Créez un notebook puis saisissez une commande Python comme print("Hello Jupyter") pour tester son bon fonctionnement.

Pour exécuter le code saisi, cliquez sur le bouton play en forme de triangle dans la barre d’outils supérieure ou appuyez sur CTRL + ENTREE.

Ajouter l’environnement au menu Jupyter¶

Enfin, afin de disposer de ce nouvel environnement dans les menus de Jupyter/Jupyterlab, il convient de l’y ajouter.

Depuis l’environnement virtuel activé, saisir ces commandes:

(formation) python -m ipykernel install --user --name=<nom environnement>  --display-name="<nom affiché dans Jupyter>"`

<nom environnement> représente le dossier qui sera créé dans la configuration de ipykernel, le nom de votre environnement sera un bon choix.

Dans notre cas, la commande finale sera:

(formation)  python -m ipykernel install --user --name=formation --display-name="Formation (Python 3.14)"

Redémmarez jupyter. Le nouvel environnement apparaîtra dans le menu du Launcher.
