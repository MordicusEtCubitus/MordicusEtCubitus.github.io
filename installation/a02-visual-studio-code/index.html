Visual Studio Code et Python

Visual Studio Code, souvent abrégé en VS code, est un éditeur de code édité par Microsoft, fonctionnant sous Linux, Windows et MacOS. C’est un éditeur très complet, comprenant de nombreuses fonctionnalités comme le support de git dans l’éditeur de code, la complétion automatique du code, ou encore la coloration syntaxique, un débugger, une fonctionnalité de refactoring du code. Nous verrons aujourd’hui comment le configurer sous Linux et le paramétrer au mieux pour l’utiliser avec Python.

Installation¶

Commencez par télécharger le logiciel depuis le site vscode puis suivez la procédure d’installation de votre plateforme

Pour des questions de confidentialité et sécurité, nous vous conseillons d’installer la version VSCodium

Bien que VSCode soit un logiciel libre, la version binaire proposée par Microsoft n’est pas sans risque de confidentialité et d’atteinte à vos données:

When we [Microsoft] build Visual Studio Code, we do exactly this. We clone the vscode repository, we lay down a customized product.json that has Microsoft specific functionality (telemetry, gallery, logo, etc.), and then produce a build that we release under our license. When you clone and build from the vscode repo, none of these endpoints are configured in the default product.json. Therefore, you generate a “clean” build, without the Microsoft customizations, which is by default licensed under the MIT license

Sous Linux, le logiciel est aujourd’hui disponible dans la majorité des dépôts des distributions Debian/Ubuntu:

Ouvrez terminal, et saisir sous Linux :

sudo apt install visual-studio-code

VS Code est installé !

Vous pouvez désormais démarrer l’exécutable. Sous Linux et Mac vous pouvez saisir la commande code dans un terminal. Sous Windows, recherchez code dans la barre de recherche.

Configuration¶

Installation du plugin python¶

Dans la barre de menu, sur le côté, cliquez sur le bouton composé de plusieurs carrés, en bas. Il vous mènera dans le gestionnaire d’extension de vscode.

Cherchez ensuite “Python” dans la barre de recherche, et installez l’extension qui s’appelle “Python IntelliSense” de Microsoft.

Note : Si vous souhaitez exécuter un notebook Jupyter avec VS code, c’est aussi possible: il existe une extension Jupyter que vous pouvez installer de la même façon.

Le plugin Python est maintenant installé ! Pour nous en assurer, créons un programme “Hello world”.

  1. Commencez par cliquer sur l’onglet “explorer”, tout en haut de la barre verticale à gauche.

  2. Cliquez ensuite sur “NO FOLDER OPENED”. Cela affichera un menu déroulant, vous permettant d’ouvrir un dossier ou de cloner un répertoire.

  3. Ouvrez un dossier en cliquant sur “open a folder” ou "ouvrez un dossier.

Note :

Dans le cas où vous auriez déjà plusieurs dossiers d’ouverts et que vous ne souhaiteriez pas les fermer, vous pouvez choisir d’ajouter un dossier, ou add a folder.
Cela ajoutera ce dossier à la liste des dossiers ouverts, sabs fermer les autres.

  1. Ajoutez un fichier python :
    Cliquez sur l’une des options entourées en rouge ou faîtes apparaitre le menu contextuel via un clic droit puis nouveau fichier.

Nommez ce nouveau fichier en utilisant l’extension .py.

Par exemple hello_world.py.

VS code reconnaît l’extension, ce qui lui permet d’effectuer la coloration syntaxique et de proposer des suggestions de complétion du code.

  1. Rédigez un petit programme Hello World.
    Exécutez le à l’aide de la flèche, en haut à droite de l’éditeur de code.
    Le programme s’exécute dans le terminal !

Vous pouvez aussi afficher le menu contectuel via clic droit de la souris dans la zone d’édition du fichier puis choisir Exécuter dans un terminal

Configuration avec l’environnement virtuel anaconda¶

Il est possible que vscode ne trouve pas votre interpréteur Python et ne puisse pas exécuter le script.

Il convient alors de s’assurer de disposer d’un interpréteur Python et de le déclarer dans le logiciel.

Dans l’environnement de VS code, utilisez le raccourci clavier ctrl + shift + P, puis cherchez Python: Select Interpreter, et sélectionnez votre environnement Python ou parcourez l’arborescence pour sélectionner son exécutable : bin/python sous Unix et python.exe sous Windows.

Si vous ne savez plus/pas ou se trouve l’exécutable de votre Python, dans un terminal avec l’environnement activé, lancez l’interpréteur Python puis saisir ces commandes:

bash ou c:> python
>>> import sys
>>> sys.executable
<affiche l'emplacement de votre python>

Note : Il existe également une extension vscode nommée Python Environment Manager qui permet de gérer les environnements virtuels provenant de diverses sources.

Installation d’un linter¶

Qu’est-ce qu’un linter ?

Un linter est un outil d’analyse statique du code, permettant de mettre en évidence des problèmes syntaxiques et stylistiques, ce qui vous permet d’identifier et de corriger des erreurs de programmations subtiles, ou des formulations qui ne sont pas conventionnelles et peuvent amener, plus tard, à des erreurs ou des bugs.

Un linter est différent d’un formateur, le linter analyse la façon dont le code s’exécuterait et indique les corrections en fonction, là où les outils de formattage s’attachent seulement à l’apparence du code.

Aujourd’hui, presque tout les projets utilisent un linter, ce qui permet d’améliorer la qualité du code et la compatibilité des différentes version d’un projet. Pour tous les langages de programmation, il existe plusieurs linters.

Pour Python, les linters supportés par VScode sont pylint, Flake8, Pylama, mypy, Bandit, pycodestyle, et Prospector.

Dans ce tutoriel, nous allons utiliser Pylint.

1. Autoriser le linter

Ouvrez la fenêtre de commandes avec ctrl + shift + p, et sélectionner Python: Select Linter. Choisissez un des linters dans la liste proposée (ici, Pylint).

2. Installer le linter

Le linter est autorisé, mais pas installé. Lorsque vous sélectionnez un linter, VScode vous ouvre une fenêtre pour vous informer de ce fait. Cliquez sur “Installer”.

Le linter est maintenant installé ! Pour le désinstaller, il vous suffira de retourner dans les paramètres avec ctrl + shift + p, et sélectionner “Python:Enable/Disable Linting”.

Utilisation du linter¶

Pour utiliser le linter, copiez collez le code ci-dessous dans votre programme (ou utilisez un autre programme de votre choix), puis utilisez la palette de commandes (ctrl + shift + P), cherchez “linting”, et sélectionnez “Python: Run Linting”.

Voici un exemple de programme à votre disposition pour tester le linter :

import time

Ce programme permet de retrouver les facteurs premiers d’un nombre nb. Ses défauts comportent :

  • Une docstring absente : on ne sait pas ce que fait ce code à moins de passer du temps à le lire et essayer de le comprendre.

  • Un print au lieu d’un return : la fonction pourrait retourner la liste, mais l’affiche à la place.

  • Le nombre de lignes blanches avant et après la fonction n’est pas conforme à la PEP8 (deux lignes avant et deux lignes après doivent rester blanches

  • Le module time ne sert à rien, il n’est pas utilisé, il devrait être supprimé.

Voici le résultat en utilisant deux linters différents :

  1. Avec Pylint

  1. Avec Pylama

Comme vous pouvez le voir sur ces images, les deux linters remarquent des choses différentes : en effet, Pylama est en réalité un paquet comprenant plusieurs outils : il possède un linter, et plusieurs formateurs de code suivant plusieurs normes différentes (PEP8, PEP257). Pylama utilise Pylint mais aussi PyFlakes. Il est donc plus complet.

Voici la fonction telle qu’elle est après toutes les corrections indiquées par Pylama :

from math import sqrt


def nombres_premiers(nb):
    i = 2
    liste = list()
    while nb % 2 == 0:
        liste.append(2)
        nb = nb / 2
    for i in range(3, int(sqrt(nb)) + 1, 2):
        while nb % i == 0:
            liste.append(i)
            nb = nb / i
    if nb > 2:
        liste.append(nb)
    return (liste)

nombres_premiers(600851475143)

Ce n’est pas parfait, il manque encore une docstring, et le nom de la fonction n’est pas très informatif quant à son utilité, elle devrait plutôt s’appeler “facteurs_premiers”. Mais le code reste beaucoup plus propre qu’au début ! Le linter facilite les revues de code.
